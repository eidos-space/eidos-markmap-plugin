# 思维导图

使用 Markmap 将 Markdown 标题和列表显示为可折叠的交互式思维导图。

需要 **Eidos Lite 0.29.0** 及以上版本和插件 API **3.7.0**。安装归档并在 Space 启用后，打开 Markdown 文件，选择思维导图视图。界面、名称和本文档跟随宿主语言；切换语言不重置展开状态或画布位置。

- 文档修改实时更新分支。
- 使用适应窗口、放大／缩小、全部展开／收起按钮。
- 拖动平移画布，点击节点圆点展开或收起子节点。
- 配色跟随 Lite 的浅色与深色外观。
- 库和样式全部打包，离线可用，不加载 CDN 脚本。

CLI Serve 不支持此文件视图；当前移动端宿主不支持此 API 3.7 归档，已有旧版安装可继续使用。

## 开发

使用 Node.js 22.12 及以上版本和 SDK/tools 0.9.0，运行 `npm ci`、`npm run check -- --target lite` 和 `npm run pack:plugin`。产物位于 `dist/`。
